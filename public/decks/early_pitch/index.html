Problem

Calibration is slow

Standard BCI protocols need 20–30 min of setup + motor calibration before therapy begins. Patients exhaust themselves before the session starts.

BCI illiteracy blocks adoption

30–50% of users cannot reliably generate motor-imagery signals. The result: abandonment, high cost per patient, and poor reimbursement.

Architecture

Spatial Context

Depth / gaze scanner picks the target and computes 6-DOF reach trajectory.

Physiological Gating

EDA / HRV / thermal stress adjusts confidence threshold dynamically.

Neural Trigger

2-class music imagery → binary “go / stop” command.

Fusion layer outputs ROS-compatible intent + gating messages to any assistive actuator.
